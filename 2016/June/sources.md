## Unresolved / judgement calls

1. **Q16 (Part A) — "in how many minutes would Chris overtake Santa".** The arithmetic (Santa 40 min, Chris 30 min, Santa starts 5 min early) gives 15 min after Chris starts; option 2 (15) is what the relative-speed calculation yields and is what the Booklet A key marks (2). No conflict with the key; recorded from the key.

2. **Q18 (Part A) — triangular-prism slabs.** The pure volume bound is 125 (option 3), but the Booklet A key marks **2 (100)**. The key value is recorded; the explanation states explicitly that the geometric working only reaches the volume bound and does not derive 100. This is a key-vs-reasoning difference, resolved in favour of the official key.

3. **Q133 (Part C) — optimal territory size.** Cost–benefit graphs normally give the optimum at maximum (benefit − cost); the Booklet A key marks **1 (A)**. Key value recorded, discrepancy noted in the explanation.

4. **Q138 (Part C) — simplest/economic/less-time-consuming marker.** Commonly argued to be RAPD, but the Booklet A key marks **4 (EST-SSR)**. Key value recorded; the alternative reasoning is noted in the explanation and here.

5. **Q79 (Part C) — minisatellite pedigree.** The autoradiograph is low-resolution; the Booklet A key marks **2 (A, B and D)**. The band reading is given as best-as-the-image-allows and the key value is authoritative.

6. **Q121 / Q111 / Q137 (Part C) — figure-option questions.** For these the option text is the figure itself; the answer number follows the Booklet A key (Q121→4, Q111→2, Q137→3).

7. **No `Question ID:-` headers** are printed in either paper source for this 2016 booklet (they post-date this paper), so the Question-ID↔number mapping could not be built from headers. Numbering instead follows the **printed question numbers** (1–145), which are identical and unambiguous across Source 1 and Source 2 and align directly with the key's "Q. No." column. This is safe here because the key is also organised by plain question number for Booklet A.

8. **Transcription fidelity.** Stems/options were transcribed from the typeset Source 1 PDF and confirmed against Source 2. Minor OCR-style artefacts in the text layer (e.g. dropped subscripts) were corrected only where the on-page image, read by vision, clearly showed the intended glyph; nothing was paraphrased. A few printed typographical oddities in the source were kept verbatim (e.g. "gens" for "genes" in Q41, "comer" for "come" in Q65, "deacytalase" in Q27, "an all nucleated cells" in Q33).
