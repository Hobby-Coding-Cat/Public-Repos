## Independence assessment

Pathfinder and IFAS are different organisations, different layouts, different numbering orders, and different PDF production dates; neither is derived from the other. Two independent sources: **requirement satisfied**.

## Structure / numbering decisions

- This is a unit-based (2011–2013 pattern) paper: Part A = Q001–020; then each unit prints its own "Part – B" and "Part – C" block with **sequential** numbering 021–145. Total 145 questions, consistent with the exam instructions reproduced on the IFAS cover page (145 = 20 Part A + 50 Part B + 75 Part C; answer 15/35/25).
- Per the archive rules for unit-based papers, PartB.md holds every question printed under a "Part – B" heading (50 questions: 21–23, 30–32, 36–41, 48–50, 60–62, 69–75, 81–83, 91–93, 100–112, 123–124, 131–134) and PartC.md holds every question printed under a "Part – C" heading (75 questions: 24–29, 33–35, 42–47, 51–59, 63–68, 76–80, 84–90, 94–99, 113–122, 125–130, 135–145), each keeping its printed number. Counts: 20 + 50 + 75 = 145. ✔
- Global figure filenames `figNN.png` use the printed question number (e.g. Q007 → fig07.png, Q057 → fig057.png zero-padded to 3 digits where the printed number is 3 digits).

## Conflicts found between sources

1. **Q005 step 4 wording**: Pathfinder prints "4. x + 5 = 1 [cancelling (x − 5) from both sides]"; IFAS prints "(iv) x-5 =1 [cancelling (x-5) from both sides]". Resolved in favour of the legible Pathfinder typeset line (x + 5 = 1), which is also the mathematically intended cancellation of (x−5); IFAS's "x−5 = 1" is judged a retyping error. Noted here per policy; transcription follows Pathfinder.
2. **Q044 key vs its own explanation**: the Pathfinder key table (p.27) gives Q044 = a (P and Q), while the Pathfinder explanation section (p.28) states "Correct option should be P and R." The key table was followed (Answer: 1, P and Q) and the discrepancy is flagged inside the Q044 explanation in PartC.md.
3. **Q016 (magnet in aluminium cylinder)**: both sources print the same options; the key answer (a, "heating the magnet") is physically debatable (eddy-current heating occurs mainly in the cylinder), but the key's verdict was used verbatim as required.
4. **Q027 parameter A**: the r¹² term is the electron-shell (exchange) repulsion; the key marks option d (dipole-dipole repulsion). Key verdict used; wording transcribed verbatim.
